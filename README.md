## Overview

Raft Mod Loader (RML) is the official modding framework for Raft, featuring an in-game mod browser accessible from the main menu, a C# API exposing crafting, building, ocean, and entity game systems, and automatic dependency and update management for the active community mod library on raftmodding.com.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Raft Mod Loader** delivers the features you need in a clean, intuitive package.

> Official website: [raftmodding.com](https://raftmodding.com)

## Key Features

| Feature | Description |
|---------|-------------|
| **In-Game Mod Browser** | Browse and install mods from the main menu without leaving the game |
| **C# Mod API** | Full C# hook API for crafting recipes, building, ocean systems, and entities |
| **Dependency Manager** | Automatically resolves and installs required mod dependencies |
| **Update Notifications** | Alerts when installed mods publish new compatibility updates |
